# 转化次数 ≤1

按每个样本的转化峰对数筛选 RI 初筛池：H/C < 1.5 且转化次数 ≤1。六个地下水样本合为 GW 来源组，50 个湖水样本合为待溯源的 Lake 受体组。相同分子按分子式对齐；一个分子式在至少一个地下水样本符合条件，即纳入 GW 初筛池。

| 其中在湖水至少一个样本检出 | 845 |
| 湖水检出的分子式中，至少一个地下水样本转化次数为 0 | 440 |

`转化次数 ≤1.xlsx` 含说明、GW 和 Lake 逐样本 RI 初筛表、GW 分子式表、GW 在湖水检出表和 GW 零次在湖水检出表。相应 CSV 也包含在本目录。

表中的湖水检出仅表示相同分子式出现在湖水样本中。由于尚无其他来源端元用于排除共有分子，也未做生态组装稳定性验证，不能把这些条目直接视为已验证的地下水特异 marker。论文的后续 marker 分子条件为 H/C < 1.5 且转化次数 =0，相关子集已单列；逐样本先算、按分子式合组及至少一个样本符合是本次操作约定。

计算沿用 200–900 Da、转化质量差 ±0.000010 Da；输入中无 C13 指示列，无法核实同位素过滤。论文补充材料 Text S2 未包含在提供的 PDF 中。
