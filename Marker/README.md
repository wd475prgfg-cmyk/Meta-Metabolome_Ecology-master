# 密云地下水和湖泊候选 marker 筛选

以每个样本内分子的转化次数 **≤1** 标记 RI。按 C/H/N/O/P/S 分子式比较两端元；同一分子式在不同样本的实测质量可有微小偏差。候选 marker 必须同时满足：

1. 在目标端元至少一个样本中检出且符合 RI≤1；
2. 在另一端元的所有样本的全部保留峰中均未检出该分子式，包括另一端元中不符合 RI 的峰。

这是 200–900 Da、现有样本与检测条件下的**候选分子式**，未检出不等于绝对不存在；相同分子式也可能对应不同结构异构体。转化匹配是质量差候选关系，不证明反应方向或真实惰性。

| 端元 | 样本数 | 完整候选 | 至少两个样本符合 RI≤1 |
| --- | ---: | ---: | ---: |
| GW | 6 | 204 | 6 |
| Lake | 50 | 4,994 | 1,490 |

GW 204 个完整候选中有 196 个仅在一个地下水样本检出；湖泊与地下水样本量分别为 50 和 6，检出机会不同，数量不能直接解释为端元差异大小。`RI_le1_at_least_2_samples` 表示至少两个不同样本中该分子式符合 RI≤1，并非已通过统计显著性或外部验证的标志物。两套清单均保留，供后续结合空白、检出限、质量控制及重复性确定最终 marker。

`Miyun_marker_candidates.xlsx` 含 `GW_candidates`、`Lake_candidates` 两个完整清单表和 `GW_RI_ge2`、`Lake_RI_ge2` 两个至少两样本支持的子集表。各表提供分子式、元素数、端元总样本数、检出样本数、RI 样本数、占比和对应样本名。

同名 CSV 提供完整清单及子集；`GW_candidate_sample_details.csv` 和 `Lake_candidate_sample_details.csv` 列出每个候选在每个检出样本中的质量、转化次数及 RI 标记；`all_formula_endpoint_comparison.csv` 包含所有分子式的两端元检出和 RI 计数。输入自带的 `RI` 相对强度列未用于本筛选。

前一步源文件没有 C13 同位素指示列、没有 Class 列；未核实同位素过滤。此结果未执行随机森林、SHAP、贝叶斯溯源或生态组装分析。
