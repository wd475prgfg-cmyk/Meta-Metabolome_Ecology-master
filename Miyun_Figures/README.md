正文建议放01、02、03、05，04放补充材料。

网络来自原始1255条数据库、±0.000010 Da含端点的整数质量匹配。每组仅建一次网络，共94951个不同峰对。最终展示地下水19个和沉积物6个来源独有、来源网络零连接且Lake检出的marker主筛候选。Lake是受体，不作为来源排除参照；Lake检出不是稳定性或定量贡献验证。匹配边不证明实际反应发生或方向。

网络图按真实代表实测m/z与H/C定位，保留全部节点与边；热图保留原始峰强、以log10着色，未作行归一化。
