# 地下水零次候选 marker：中间结果

Lake 的 50 个样本是待溯源受体；6 个 GW 样本合为一个地下水来源组。参考毛等 WR 论文，先按样本筛选 H/C < 1.5 且转化次数 =0，再按分子式合并。此处采用的重复样本约定是：至少一个地下水样本符合上述条件，就进入来源候选池；论文正文未明确该约定，补充材料 Text S2 未随论文提供。

现有数据得到 510 个地下水候选分子式，其中 440 个在至少一个湖水样本检出、70 个未在现有湖水样本检出。**这些是未完成其他来源端元排重的中间候选，不是已确认的地下水独有 marker。** Lake 是受体，湖水检出不作为来源共有分子的排除条件。

`地下水零次候选marker.xlsx` 包含全部候选、湖水检出与未检出子表、逐样本明细及峰强矩阵。峰强直接取用户输入的 `intens` 列，没有在此步骤重新归一化；矩阵空白表示该样本未检出，不表示已测得峰强为零。`GW候选_湖水检出.csv` 与 `候选_逐样本明细.csv` 为相应机器可读表。

当前网络沿用 200–900 Da 与 ±0.000010 Da 匹配容差，输入无 C13 同位素指示列，无法核实同位素过滤。只有进一步引入其他真实来源端元，排除多个来源共有分子，并按研究方案验证重复性和稳定性后，才能确定来源特异 marker。
